# Capstone — Charter & Scope

## Purpose

Demonstrate CLO6: design and defend a complete project management plan for a
realistic software or data project, integrating ethics, governance,
sustainability, and AI-assisted practice.

## Scope of the deliverable

The capstone is a **plan + defense**, not a built product. Teams produce:

1. **Charter** — objectives, success criteria, sponsor role, authority
2. **Master plan** (draft at L27, final at L32):
   - Scope baseline: WBS + dictionary
   - Schedule baseline: estimates, network, Gantt, milestones
   - Cost baseline: bottom-up budget, contingency with justification
   - Quality plan incl. data-quality rules (data projects)
   - Risk register with responses, owners, triggers
   - Communication + stakeholder engagement plan
   - Tailoring justification: what was cut from heavyweight practice and why
3. **Process evidence** — sprint/board history from the semester's labs
4. **Defense** — 10-minute presentation + 5-minute Q&A per
   [format](defense-format.md)

## Project eligibility

- Seed catalog projects (MEDSYNC, TELCOCARE, CAMPUSHUB, GRIDSENSE), or
- instructor-approved external/employer project with a written sponsor brief,
- no live production systems; synthetic or public data only.

## Two equivalent tracks

Teams choose **one track**; both are graded with the same rubric and defend
in the same session.

| | **Software PM track** (CS-lean) | **Data Science PM track** (DS-lean) |
|---|---|---|
| Typical project | Portal/platform feature build (e.g., CAMPUSHUB module) | ML product or pipeline (e.g., TELCOCARE churn, GRIDSENSE anomaly alerts) |
| Scope baseline | Feature-oriented WBS | Pipeline-stage WBS: ingestion → features → model → serving → monitoring |
| Schedule shape | Sprint-based with integration/UAT milestones | Experiment-gated: discovery spikes feeding training milestones |
| Cost emphasis | Person-months, licenses | Compute hours, storage, cloud price volatility |
| Quality plan | Test coverage, defect density | Data-quality rules + model fairness thresholds |
| Extra required section | — | **Model risk gate**: metrics, fairness bounds, monitoring, rollback |
| Both tracks include | Full baselines, risk register, communication plan, tailoring justification, ethics + AI-use disclosure | Same |

## Team accountability

Individual contribution memo (≤ 300 words, private to instructor) accompanies
the final submission; rubric dimension *individual contribution* is scored
from it plus observed process evidence.
