# Peer Review Form (capstone)

Two peer-review instruments run in this course: the **M3 red-team exchange**
(plan drafts, structured) and **defense peer scoring** (feedback only, never
a grade). Both use this page; the red-team form is submitted to the LMS and
*also handed to the reviewed team*.
