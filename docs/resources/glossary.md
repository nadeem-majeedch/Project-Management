# Glossary

Working definitions follow PMBOK 7 (PMI, 2021) unless noted. Terms are added
as lectures introduce them.

| Term | Working definition |
|---|---|
| Baseline | Approved version of scope/schedule/cost used for comparison; changes only via change control |
| BAC | Budget at completion — total authorized budget |
| CPI | Cost Performance Index = EV ÷ AC; < 1 means over cost |
| SPI | Schedule Performance Index = EV ÷ PV; < 1 means behind schedule |
| Contingency reserve | Budget for identified risks ("known-unknowns"); PM controls |
| Management reserve | Budget for unidentified work ("unknown-unknowns"); sponsor controls |
| Critical path | Longest duration path through the network; zero total float |
| CCB | Change Control Board — approves/rejects baseline changes |
| Definition of Done | Team's shared completion criteria for work items |
| EMV | Expected Monetary Value = probability × monetary impact |
| EV / PV / AC | Earned, Planned, and Actual values of work (EVM inputs) |
| Fast-tracking | Compressing schedule by overlapping sequential activities; adds rework risk |
| Crashing | Compressing schedule by adding resources to critical activities; adds cost |
| Float (total) | Slack between EF and LF of an activity without delaying the project |
| Iron triangle | Scope–time–cost trade-off framing (with quality as an output) |
| Little's Law | WIP = throughput × cycle time (flow systems) |
| Monte Carlo simulation | Sampling many scenario outcomes to get schedule/cost distributions |
| P80 | Value at 80% confidence from a simulation distribution |
| PERT estimate | (O + 4M + P) ÷ 6 — weighted three-point expected value |
| Psychological safety | Shared belief that interpersonal risk-taking is safe on this team |
| RACI | Responsible, Accountable, Consulted, Informed role matrix |
| Residual risk | Risk remaining after responses are applied |
| Secondary risk | New risk created by applying a response |
| Sprint | Fixed-length Scrum iteration (Scrum Guide 2020) |
| Tailoring | Deliberately adapting method, artifacts, and governance to project context |
| WBS | Work Breakdown Structure — deliverable-oriented hierarchy of project work |
| Work package | Lowest WBS level; controllable unit with owner and estimate |
| **Governance & responsible-AI terms** | |
| Data governance | The system of decision rights and accountabilities for an organization's data — who may collect, change, share, and delete data, under what controls |
| Data steward | The named person accountable for a dataset's quality, access rules, and fitness for use |
| Data-quality rule | An enforceable, testable assertion about a dataset (e.g., "customer_id is unique and non-null"), wired into pipeline gates |
| Data-quality gate | A checkpoint in a data/ML pipeline that blocks promotion to production when rules or metrics fail |
| Model risk gate | Evidence-and-approval checkpoint a model must pass before release: metrics, fairness thresholds, monitoring, rollback plan |
| Model card | A short structured document reporting a model's intended use, training data, performance across groups, and limitations |
| Model drift | Degradation of a deployed model's performance as world or data distributions change |
| Fairness threshold | A pre-agreed acceptable bound on a fairness metric (e.g., maximum approval-rate gap across groups) that a model must meet before release |
| Bias (systematic) | Systematic error in data, labels, or design that produces unfair or skewed outcomes for particular groups |
| Privacy by design | Building data minimization, consent, and access controls into project plans rather than retrofitting them |
| Data minimization | Collecting and retaining only the data the stated purpose requires |
| AI disclosure statement | A submission note declaring which AI tools were used, for what, and how outputs were verified (see the course's integrity policy) |
| PICT | Privacy, Integrity, Confidentiality, Transparency — the course's four-lens ethics checklist for data-project decisions |
| Governance gate | A scheduled decision point (stage gate) where a named body reviews evidence and authorizes continued investment |
| Decision rights | The explicit assignment of who may make which class of decision (vs RACI's consultation/accountability rows) |
