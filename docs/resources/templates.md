# Templates

**The full template library now lives in [templates/](../templates/index.md)**
— 15 fill-in Markdown artifacts plus spreadsheet-compatible CSV worksheets
and the CAMPUS-MEND scenario data files. The table below is the quick map
from the original course plan; see the library page for the maintained list.

| Template | Used in | Fields |
|---|---|---|
| Project charter | Lab 1, capstone | objectives, success criteria, sponsor, authority, high-level milestones |
| Stakeholder register | Lab 2 | name, role, power, interest, current→desired engagement |
| WBS + dictionary | Lab 3, A2 | 3-level tree; per-package owner, estimate, acceptance |
| Risk register | Lab 7, A3 | ID, cause-risk-effect, P×I, response, owner, trigger, residual |
| Decision tree / EMV sheet | A3 | options, probabilities, payoffs, expected values |
| Sprint plan + DoD | Lab 9 | goal, capacity, backlog, DoD checklist |
| Communication matrix | Lab 12 | audience, channel, cadence, owner, purpose |
| Closure checklist | L30 | acceptance, contracts, access, archive, recognition |

Format: markdown templates are the fill-in files linked from the
[library index](../templates/index.md); CSV worksheets live under
[`templates/data/`](../templates/index.md#csv-spreadsheet-compatible-worksheets-data)
and are identical to what each lab's brief expects.
