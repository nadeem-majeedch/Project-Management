# Standards Library

Standards this course anchors to. **Editions matter** — cite them exactly
like this in coursework.

| Standard | Body / year | Where used |
|---|---|---|
| PMBOK Guide, 7th ed. | PMI, 2021 | principles & performance domains (L03 backbone); vocabulary throughout |
| PMBOK Guide, 6th ed. | PMI, 2017 | process & ITTO vocabulary (certification-era terminology) |
| ISO 21502:2020 | ISO, 2020 | governance vocabulary (L02, L28) |
| ISO 31000:2018 | ISO, 2018 | risk process backbone (L15–L17) |
| The Scrum Guide, 2020 | Schwaber & Sutherland | Scrum mechanics (L21) |
| Agile Manifesto | 2001 | adaptive values (L21–L24 framing) |
| PMI Code of Ethics & Professional Conduct | PMI | ethics backbone (L28) |
| PMI Talent Triangle | PMI | competency framing (L04) |

## Reading guidance

- The university library provides PMI standards through its subscription;
  check before purchasing.
- PMBOK 8 is referenced only where publicly documented and marked
  "verify before publication" — it is **not** required reading this semester.

## Citation style for coursework

> PMI. (2021). *A guide to the project management body of knowledge
> (PMBOK guide)* (7th ed.). Project Management Institute.

Copy the pattern for any standard: body. (year). *title* (edition). publisher.
