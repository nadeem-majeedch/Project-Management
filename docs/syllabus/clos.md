# Course Learning Outcomes (CLOs)

Six measurable outcomes govern everything in PM-401: each lecture, each
assessment, and the capstone trace to them. The full matrices live in the
[detailed syllabus](detailed-syllabus.md); this page is the reference copy.

## The six outcomes

| ID | On completing the course, a student can… | Bloom |
|---|---|---|
| **CLO1** | **Given** a PMBOK 7 domain map, define and classify the 12 principles, 8 performance domains, and predictive/adaptive/hybrid life-cycle models; **given** a vignette, justify a life-cycle choice with ≥ 3 criteria | Understand |
| **CLO2** | **Given** a project brief, produce scope statement, WBS (100% rule), three-point estimates, and a CPM schedule with floats, then defend planning choices | Apply |
| **CLO3** | **Given** schedule and cost data, compute the full EVM set (PV, EV, AC, CV, SV, CPI, SPI, EAC variants, TCPI) and diagnose project health with a written recovery direction | Analyze |
| **CLO4** | **Given** a project context, construct a risk register with probability–impact analysis, EMV, and response strategies aligned to ISO 31000, and re-plan after a simulated risk event | Analyze |
| **CLO5** | **Given** a team scenario, select and apply adaptive practices (Scrum events, Kanban WIP limits, Little's Law) and communication/negotiation techniques for stakeholder alignment | Apply |
| **CLO6** | **Given** an integrated project, defend a master plan whose artifacts are mutually consistent — governance, data-quality rules, responsible-AI gates, and benefits realization included | Evaluate |

## CLO → assessment coverage

Every component is mapped to the CLOs it principally assesses; details and
weights on the [grading page](../assessments/grading.md).

| Component | Weight | Primary CLOs |
|---|---|---|
| A1 Quizzes (best 2 of 3) | 10% | CLO1, CLO2, CLO5 |
| A2 Assignment 1 — Scope & Schedule | 10% | CLO2 |
| A3 Assignment 2 — Risk Register | 10% | CLO4 |
| A4 Assignment 3 — EVM Analysis | 10% | CLO3 |
| A5 Midterm (L01–L20) | 20% | CLO1–CLO4 |
| A6 Case portfolio | 10% | CLO1, CLO4, CLO6 |
| A7 Capstone plan & defense | 25% | CLO2–CLO6 |
| A8 Final exam | 5% | CLO1, CLO6 |

- **CLO4** — U4 (L15–L18); A3; Lab 9–11
- **CLO5** — U5 (L21–L26); Quiz 3; capstone teamwork
- **CLO6** — L27–L32; capstone defense; final exam
