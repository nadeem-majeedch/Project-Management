# About PM-401

## The course in one paragraph

PM-401 is a 16-week, 32-lecture project-management course built for
7th-semester software and data students. It is standards-anchored (PMBOK® 7,
ISO 21502, ISO 31000, the Scrum Guide) but artifact-driven: every concept
lands in something you produce — a charter, a WBS, a cost baseline, a risk
register, an earned-value diagnosis — and the semester ends with a team
capstone plan defended before a panel.

## Design principles

1. **Constructive alignment.** Six measurable CLOs map to lectures, to
   assessments, and back again; the
   [assessment strategy](assessments/assessment-strategy.md) publishes the
   whole matrix rather than describing it.
2. **Two disciplines, one course.** Software engineering and data science
   tracks run in parallel everywhere — CS examples use build/test/deploy
   settings; DS examples use data readiness, model gates, and compute
   footprints.
3. **Honest numbers.** Every calculation taught in the course is
   machine-verified: the critical paths, EVM chains, and risk scores in the
   labs and cases are recomputed by validation scripts before publishing.
4. **Progressive difficulty.** 105 case studies run from beginner (CS-01) to
   expert (CS-105); the [case directory](cases/index.md) organizes them by
   band and tag.
5. **Open student layer, protected instructor layer.** All student materials
   are published here; answer keys and facilitation notes never are — the
   build fails if that separation breaks.

## Standards and sources used

  Guide)*, 7th ed.
- PMI (2017) *PMBOK® Guide*, 6th ed. (process vocabulary)
- ISO 21502:2020 — project, programme and portfolio management
- ISO 31000:2018 — risk management guidelines
- Schwaber & Sutherland (2020) *The Scrum Guide*
- Anderson (2010) *Kanban*
- The full annotated list lives in [Textbooks & References](syllabus/textbooks.md).

## About this site

The site is static MkDocs Material, rebuilt reproducibly from the
[repository](https://github.com/nadeem-majeedch/Project-Management). Student
pages are hand-authored or generated from course YAML; instructor materials
live outside the published tree. Data on the site (schedules, lecture maps,
case metadata) comes from single-source YAML files so the curriculum never
drifts between pages.

## Repository and license
