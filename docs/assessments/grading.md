# Grading & Components

## Grade composition

| ID | Component | Weight | CLOs | Details |
|---|---|---|---|---|
| A1 | Quizzes (best 2 of 3) | 10% | CLO1, CLO2, CLO5 | 15 minutes, start of lecture (L04, L12, L26); lowest score dropped |
| A2 | Assignment 1 — Scope & Schedule | 10% | CLO2 | WBS + three-point estimates + CPM network + baselined Gantt |
| A3 | Assignment 2 — Risk Register & Responses | 10% | CLO4 | ISO 31000-aligned register with response plans and owners |
| A4 | Assignment 3 — EVM Case Analysis | 10% | CLO4 | Compute full EVM set, diagnose, recommend recovery |
| A5 | Midterm Exam | 20% | CLO1–CLO4 | L01–L20, quantitative emphasis (CPM, EVM, PERT) |
| A6 | Case Portfolio | 10% | CLO1, CLO2, CLO4, CLO5 | 12 analyses × 300–500 words; ≥ 3 per unit; no repeated domain |
| A7 | Capstone Project & Defense | 25% | CLO5, CLO6 | Team master plan + 10-min defense + Q&A |
| A8 | Final Exam | 5% | CLO1, CLO6 | Comprehensive; emphasis L21–L32 |

Constraints: ≥ 40% on the midterm is required to pass the course; the
capstone defense is mandatory to earn A7 credit.

## Rubric dimensions (summary)

| Component | Dimensions | Levels |
|---|---|---|
| Case portfolio | concept accuracy · technique application · assumption honesty · communication | 4-point each |
| Capstone plan | completeness · internal consistency · tailoring justification · risk realism · communication | 4-point each |
| Capstone defense | plan quality · Q&A · team process evidence · individual contribution | 4-point each |
| Lab reports | task completion · correctness · reflection | 4-point each |

!!! warning "Instructor decisions — values to be confirmed in week 1"
    The following values are **deliberately unspecified** and are the
    instructor's decision; they are announced on the LMS and in the L01
    briefing, never silently defaulted here:

    1. **Rubric conversion** — how 0–3 rubric levels map to component
       percentages (e.g., a level-to-point table) for A6 and A7.
    2. **Second pass threshold** — besides midterm ≥ 40%, whether any other
       component carries a minimum for passing the course.
    3. **Participation** — v1.1 assigns no separate participation grade; if
       the instructor converts in-class case work into a graded component,
       weights will be re-announced before week 1.
    4. **Lab credit ceiling** — labs are pass/refine completion gates in
       v1.1; whether completed-and-refined labs add a bonus (and its cap)
       is the instructor's call.
    5. **Appeals second referee** — for re-grade requests beyond the standard
       one-week window, whether a second referee is used.

| CLO | Assessed by |
|---|---|
| CLO1 | Quizzes, Midterm, Case Portfolio, Final |
| CLO2 | Quizzes, Assignment 1, Midterm, Case Portfolio |
| CLO3 | Midterm (see note below) |
| CLO4 | Quizzes, Assignments 2–3, Midterm, Case Portfolio, Capstone checkpoint |
| CLO5 | Quizzes, Case Portfolio, Capstone |
| CLO6 | Capstone, Final |

!!! note "CLO3 coverage"
    CLO3 (cost, budget, quality planning) is formally assessed in the midterm
    and practiced continuously through cases CS-17, CS-26, CS-57, CS-62 and
    the capstone budget section. Coverage breadth is flagged for review after
    the first delivery.
