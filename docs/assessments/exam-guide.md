# Exam Guide (A5 Midterm · A8 Final)

## Midterm — L01–L20 (20%, A5)

| Fact | Detail |
|---|---|
| Timing | Week 10–11 window (announced on the LMS) |
| Duration | 90 minutes, 40 marks |
| Coverage | L01–L20 · CLO1–CLO4 |
| Pass rule | **≥ 40% (16/40) required to pass the course** |
| Format | Concepts MCQ (6) · planning math (16) · EVM control (10) · judgment (8) |

**A formula sheet is supplied** — PERT, CPM pass definitions, the EVM
indicator table, and the budget build-up. You are tested on application and
diagnosis, not on remembering constants. The numeric problems are structurally
identical to: the [Lab 4](../labs/lab-04-cpm-network.md) network,
[Lab 6](../labs/lab-06-gantt-resources.md)-adjacent budget build-up, and
cases [CS-15](../cases/CS-15.md), [CS-17](../cases/CS-17.md),
[CS-26](../cases/CS-26.md) — if you can produce those artifacts cold, the
midterm's math is within reach.

**Preparation priorities, in order of marks at stake:**

1. Run a full forward/backward pass on a fresh 14-activity network — from
   zero, in under 15 minutes. This single skill spans Q7's 10 marks.
2. Rebuild the bottom-up budget chain from raw hours (labor → indirects →
   subtotal → contingency → baseline → reserve → cap check). Know *who*
   controls each layer and what a cap breach forces.
3. Compute the full EVM set and, more importantly, *say what the numbers
   mean* — EAC₁ vs EAC₂ is an assumptions question, TCPI is a credibility
   question.
4. Judgment questions grade the **argument**, not the conclusion — practice
   writing two-sided trade-offs in three sentences.

## Final — comprehensive, emphasis L21–L32 (5%, A8)

| Fact | Detail |
|---|---|
| Timing | Exam week |
| Duration | 60 minutes, 20 marks |
| Coverage | Comprehensive; emphasis L21–L32 · CLO1, CLO6 |
| Format | Sweep MCQ (6) · scenario judgment (6) · case analysis (8) |

The final's case-analysis section is ethics/governance-centered — the
[CS-90](../cases/CS-90.md) and [CS-104](../cases/CS-104.md) patterns
(escalation sequences, benefits decomposition) are the two shapes to master.

## Rules common to both

- Seated, single-sitting exams; versions A/B differ numerically, not
  structurally.
- Method marks exist: a correct method with an arithmetic slip loses 1 mark
  per slip (capped); a wrong method loses the item regardless of the answer.
- Scripts under the midterm pass threshold are individually reviewed before
  grades are released — the threshold is a gate, not an automatic fail of
  the course.
- Re-grade requests follow the [policies](policies.md) one-week window.
