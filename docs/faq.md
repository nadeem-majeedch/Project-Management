# FAQ

Practical answers to the questions students actually ask. Where an answer has
an authoritative page, the link wins over this summary.

## Getting started

**Do I need prior project-management knowledge?**
No. L01 assumes zero PM background. The course's own
[prerequisites](syllabus/course-description.md#prerequisites) are programming
and basic statistics maturity, not PM experience.

**Which textbooks do I need to buy?**
None are mandatory. The anchor text is the PMBOK® Guide 7th edition (access
details on the [textbooks](syllabus/textbooks.md) page); everything else is
provided — [lecture notes](lectures/index.md), [labs](labs/index.md), and
[templates](templates/index.md).

**I'm a Data Science student. Is this course for me?**
Yes — every topic carries parallel CS and DS treatment: data-quality rules,
model-risk gates, GPU procurement and footprint, and ML capstone tracks are
first-class content, not add-ons.

## Work and grading

**How much work per week?**
2 h lecture + ~2 h lab + ~4–6 h reading, portfolio work, and the capstone.
The [weekly schedule](syllabus/weekly-schedule.md) shows when the peaks fall.

**What if I miss a quiz?**
Quizzes run best-2-of-3: one miss is absorbed with no documentation. A second
miss needs documented justification — see [policies](assessments/policies.md).

**Can I work in a team on assignments?**
Assignments A1–A3 are individual; the capstone is a team artifact with an
individual defense contribution. Each brief states its own rule (see
[assignments](assignments/index.md)).

**How do the 105 case studies work?**
They are graded in a portfolio (see
[case-portfolio guidance](assessments/assessment-strategy.md)) — you choose
cases across difficulty bands from the [case directory](cases/index.md), and
write structured analyses. Beginner cases start at CS-01; expert cases
(CS-76+) are optional stretch credit.

**Is there a curve?**
No. The [grading page](assessments/grading.md) lists fixed component weights;
the midterm ≥ 40% rule is the only gate.

## Tools and coursework

**What software do I need?**
A spreadsheet application for labs, a Markdown editor for templates, and a
browser. Optional: the seeded Monte Carlo script (Lab 11) runs in plain
Python 3.12 with no packages.

**Can I use AI tools for coursework?**
Within the [responsible-AI policy](assessments/academic-integrity.md):
permitted for brainstorming and outlining with attribution; not permitted for
final artifact text or any computation you cannot verify. The rule of thumb
taught in L31: *the signature on the artifact is yours.*

**Where are the templates?**
The [template library](templates/index.md) has 16 Markdown templates plus CSV
worksheets — the same files referenced from labs and the capstone.

## Access

**Where are the answer keys?**
Instructor-only. Student materials never include model answers; keys are used
for feedback after grading. If a lab says "compare with the reference," your
instructor distributes that reference in class.
