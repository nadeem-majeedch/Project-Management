# Assignment 1 — Scope & Schedule (A2, 10%)

**CLO2** · Released after L14 · Due after L16 · Individual

## Task

Choose a project from the seed catalog (CAMPUSHUB, MEDSYNC, TELCOCARE,
GRIDSENSE — or propose one for approval) and produce:

1. **Scope statement** with explicit in/out lists and acceptance criteria
2. **WBS** to work-package level (≥ 3 levels, 100% rule), plus dictionary
   entries for two packages
3. **Estimates** for all packages: three-point (O/M/P) with PERT expected
   values, plus a half-page note on your estimating basis
4. **CPM network** (AON): forward/backward pass, critical path, float table
5. **Baselined Gantt** for a 10-week window, including milestones

## Deliverables & weight guide

| Artifact | Weight |
|---|---|
| Scope statement + WBS + dictionary | 30% |
| Estimates + rationale | 25% |
| CPM network + float table | 25% |
| Gantt + milestone logic | 20% |

## Constraints & integrity

- 20–30 work packages is typical; fewer means shallow decomposition.
- State every assumption; unsupported precision costs more than honest ranges.
- AI drafting tools allowed **with disclosure** per course policy; the
  network math must be verifiably yours (show the pass).
