# Lab 16 Answer Key — Capstone Integration Pack

## Consistency audit (the six checks — grading sheet)

| # | Check | Pass requires | Typical failure |
|---|---|---|---|
| 1 | WBS hours = budget labor; S-curve cumulative = baseline exactly | totals reconcile at every parent; cumulative closes | rounding drift between WBS and budget tabs |
| 2 | Dictionary acceptance criteria = quality-plan verification rows | every QO traces to ≥ 1 criterion; every criterion has a QO home | orphaned QOs or unverified criteria |
| 3 | Register High/Critical funded; triggers = dashboard rows | each High/Critical action appears in View 4 | triggers live only in the register |
| 4 | Network finish = Gantt finish = charter milestones | all three name the same week | charter promises wk 17; Gantt silently 18 |
| 5 | Register IDs = comms rows = committee view | same IDs across all three | comms plan invents new stakeholders |
| 6 | Deadline constraint honored in every artifact | no artifact quietly moves the fixed date | recovery plan forgets the SLA evidence gate |

## Tailoring statement (model)

For a predictive-plus-data project of this size: full artifacts for scope/
schedule/cost/risk; **merged** stakeholder register into the comms plan
(one artifact, two views); **cut** formal procurement plan (single SOW,
covered as a constraint + R1/R7 risks) — justified by L08 criteria:
requirements volatility low post-charter, regulatory exposure via the
calendar rule (evidence gates kept), feedback cadence weekly (dashboard),
team co-located (no distributed-comms artifact). Students must show criteria
→ decision; "we kept everything" is a fail — real tailoring cuts something
and defends it.

## Weakest-three fix sprint (facilitation)

Expect the weakest artifacts to be: cost baseline (arithmetic drift),
comms plan (needs-first discipline), tailoring statement (missing entirely).
The 30-minute fix sprint should produce committed edits, not notes; punch
list for the rest with owners/dates before the L27 draft.

## Peer-swap probe guide (what "confusing" predicts)

- Confusion about *why an artifact exists* → defense panel question
  "what decision does this artifact serve?"
- Confusion about *numbers* → panel asks for the chain live (WBS → budget →
  S-curve → EVM).
- Confusion about *tailoring cuts* → panel attacks the cut artifact's
  absence.
Have teams write the panel-style question their confusion suggests — those
questions seed the mock-defense list for L32 prep.

## Common wrong answers

| Error | Correction |
|---|---|
| Audit marked PASS by assertion | each check needs the evidence (totals, IDs, weeks) written down |
| Tailoring = zero cuts | rubric rewards justified cuts; completeness is not the goal |
| Punch list without owners | integration work without owners repeats the E-claim pattern |
| Peer feedback ignored | the swap IS the mock defense; triage or waste it |

## Reflection guidance

1. Most common failed check: #1 (hours/cumulative drift) — the same root
   cause as real reporting failures: artifacts maintained by different hands
   without a reconciliation routine.
2. Tailoring cuts invite the panel's "why is there no X?" — the defense is
   the criteria chain, made at L08, restated confidently.
3. "More than the sum of files": the consistent ID systems (risks →
   dashboard rows; stakeholders → comms rows) mean any number can be
   traced to its source in one hop — that is the artifact that isn't a file.

## Preparation notes

Grade the audit sheet, not the pack (the pack's graded moment is L27). Log
which checks fail per team — repeat failures in the L27 draft grade the
integration dimension down, and you will want the pattern evidence.
