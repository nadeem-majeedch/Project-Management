# Rubric — Lab Reports (pass/refine)

Each lab produces one artifact (see `docs/labs/index.md`, 16 labs). Grade
per lab: **pass** / **refine** (once) against the three dimensions; two
refines needed → escalate to office hours before resubmission. Lab credit
above the completion gate (bonus, cap) is an instructor decision flagged on
the grading page.

| Dimension | Pass looks like |
|---|---|
| Task completion | all required fields filled; nothing template-empty |
| Correctness | technique applied correctly — verified against `instructor/lab-solutions/` keys and, where numeric, `tools/check_answers.py` values |
| Reflection | 3–5 sentences on what was hard and what the artifact changed in the student's thinking |

## Per-lab artifact checklists (CAMPUS-MEND scenario unless noted)

Fill before delivery week; keep in this file so grading is consistent
across semesters.

- **Lab 1** charter: objectives SMART? sponsor named? success criteria
  measurable and verifiable?
- **Lab 2** stakeholders: ≥ 10 entries with exchanges? grid placed with
  evidence? engagement-gap plan for 3 stakeholders?
- **Lab 3** scope/WBS: in/out + exclusions? 100% rule holds (§A roll-up
  310 h)? dictionary for 2 packages?
- **Lab 4** network/CPM: ES/EF/LS/LF complete on the §A network? CP =
  17 weeks found? compression memo consistent with the float table?
- **Lab 5** dictionary: entries cover effort, owner, acceptance criterion?
  duplicates resolved by newest-wins rule?
- **Lab 6** Gantt/resources: baseline set? overallocation resolved within
  float (two-tester load check)? moves justified?
- **Lab 7** cost baseline: bottom-up = labor 3,225,600 chain? S-curve funds
  from the cap? contingency separate from reserve?
- **Lab 8** quality plan: metrics have provenance? data-quality rules
  classed correctly? QA-role capacity arithmetic honest?
- **Lab 9** risk register: ≥ 15 risks normalized cause→risk→effect? scores
  match the checker values? every High risk has an owner?
- **Lab 10** P×I matrix: bands applied per the threshold table? EMV column
  computed for the quantified subset?
- **Lab 11** Monte Carlo: seeded run reproducible? P50/P80 stated with the
  deadline-gap interpretation?
- **Lab 12** communication plan: every grid quadrant covered? cadences have
  owners and triggers?
- **Lab 13** EVM/recovery: full indicator set from `evm-status-wk9.csv`
  (CV −4,800 chain)? TCPI credibility argued, not just computed?
- **Lab 14** sprint planning: capacity chain correct (32 points, not 33)?
  IN/OUT marks defensible against the goal?
- **Lab 15** change/recovery: impact-priced memo? re-baseline posture
  consistent with the CPI evidence?
- **Lab 16** capstone pack: integration complete — artifacts cross-reference
  (network↔Gantt↔budget↔risk)? ready for the M3 red-team exchange?
