# Answer Keys & Facilitation Notes

- `case-index.md` — **generated** from `planning/case-catalog.yaml`; full
  summaries of all 105 cases with use-lanes. Do not hand-edit.
- Per-case facilitation notes (`CS-<id>.md`) — **authored by instructor** as
  cases are delivered: expected solution shape, common wrong answers,
  discussion hooks, timing. One file per anchored case is enough to start.

Distribution rule: model answers never go to the LMS before the case runs in
class; exam-use cases (17 marked `exam` in the catalog) keep two variants.
