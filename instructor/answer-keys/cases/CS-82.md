# Answer key — CS-82 · Recovery by descope: the re-forecast arithmetic

> **INSTRUCTOR ONLY — not published to the site.**

**Model answer:** Evidence-tested re-forecast

## Reasoning

CPI = SPI = 0.818. EAC₁ (old baseline) = 4,000,000/0.818 ≈ 4,888,889, VAC ≈ −888,889. Re-based: BAC′ = 3.7M; EAC = 2,200,000 + (3,700,000 − 1,800,000)/0.95 = 2,200,000 + 2,000,000 = 4,200,000 → VAC′ = −200,000. The descope buys 300k; the efficiency assumption does the rest of the work — 1,900,000/0.818 would be 2,323,000, so the assumption is worth ~323k of forecast. Evidence test for 0.95: the three most recent completed packages' actual efficiency (if the last three packages ran ≥0.9, the 0.95 has a basis; if they ran 0.8, the assumption is hope dressed as planning); the specific causes of the 0.818 (if pricing errors now fixed, improvement is plausible; if the cause is chronic estimation optimism, it is not); the recovery plan's named mechanism (what changes in month 9 that did not in months 5–8). Decision: accept the re-forecast conditionally — re-baseline at 4.2M with a month-10 checkpoint; if realized efficiency by then is below 0.88, the forecast reverts to EAC₁ logic and the sponsor hears it then, not at month 14.

## Alternatives and evaluation criteria

- No descope, accept 4.89M: honest but expensive; defensible if the descoped scope is genuinely optional — the case's scope was 'budgeted', which is not the same as wanted.
