# Answer key — CS-47 · Resource leveling without moving the deadline

> **INSTRUCTOR ONLY — not published to the site.**

**Model answer:** Float-aware leveling

## Reasoning

Loads: wk1 = 20, wk2 = 40, wk3 = 20+20+20 = 60 (over by 20), wk4 = 20, wk5 = 20. Moving T3 one week later (start wk4) draws on its 2-week float: loads become 20/40/40/40/20 — all within capacity, finish unchanged because T3 still ends in wk5... the float absorbs it exactly. Moving T2 instead would consume its only float week and put it at zero float — worse, because it converts a near-critical task into critical. The histogram before/after is the evidence; the float ledger is the permission slip.

## Alternatives and evaluation criteria

- Adding a contractor for week 3: works, costs money, and hides the planning gap that float analysis already solved for free.
