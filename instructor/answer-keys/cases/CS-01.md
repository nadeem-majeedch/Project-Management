# Answer key — CS-01 · Iron-triangle autopsy of a failed ERP rollout

> **INSTRUCTOR ONLY — not published to the site.**

**Model answer:** Constraint-conflict diagnosis

## Reasoning

The budget was frozen before requirements existed, so scope growth (customizations doubling) could not be absorbed by cost; time then absorbed it via slips. The binding constraint is scope-vs-cost: the university never re-baselined either after requirements stabilized, so every customization became an unfunded change. Quality degraded last (registrar distrust) as the residual constraint absorbed pressure.

## Alternatives and evaluation criteria

- Time-as-binding argument: defensible if you weight the two missed go-lives as the primary damage; weaker because slips are a symptom, not the lever.
- Quality-as-binding: defensible if you treat registrar refusal as the real blocker; weaker because trust loss followed schedule slips.
## Facilitation

Push students to see that 'everything failed' is a symptom list; diagnosis requires choosing the lever that, if moved, would have changed the outcome.
