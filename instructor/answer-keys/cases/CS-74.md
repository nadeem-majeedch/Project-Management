# Answer key — CS-74 · Fairness metrics on the new cohort

> **INSTRUCTOR ONLY — not published to the site.**

**Model answer:** Slice fairness evaluation

## Reasoning

Postpaid: precision = 320/360 = 0.889; recall = 320/380 = 0.842; flag rate = 360/1000 = 0.36. Prepaid: precision = 90/200 = 0.45; recall = 90/300 = 0.30; flag rate = 200/1000 = 0.20. Flag-rate ratio (prepaid/postpaid) = 0.556 — far outside [0.8, 1.25]. The precision gap (0.889 vs 0.45) means prepaid flags are half noise; the recall gap means real churners go unflagged. Disposition: this is not carve-out material — prepaid customers churn fastest, so excluding them abandons exactly the population the product exists for. Fix in-model: segment-specific thresholds (raise prepaid precision at equal recall), more prepaid-weighted training data, and feature review (the prepaid signal set is thinner). Interim: document-and-ship with the disparity on the model card, manual review of prepaid flags, monthly slice re-evaluation as the monitoring gate. The governance board needs exactly the six numbers and the ratio — the table is the argument.

## Alternatives and evaluation criteria

- Carve-out: defensible only if the business process for prepaid retention exists separately; it does not, so the carve-out converts model unfairness into service absence.
