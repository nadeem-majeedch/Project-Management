# Answer key — CS-59 · The regulator arrives mid-project

> **INSTRUCTOR ONLY — not published to the site.**

**Model answer:** Emergent-stakeholder re-plan

## Reasoning

The regulator enters as high-power/high-interest immediately — residency is a compliance fact, not an opinion. Register: owner = PM with compliance officer; cadence = monthly written, on-demand reviews. Impact trace: the foreign analytics cloud sits under feature pipeline and the monitoring stack; residency forces in-country processing or a regional mirror — the pipeline workstream re-plans first (data gravity), monitoring second (can aggregate outbound). This is why stakeholder analysis precedes architecture: a register without the regulator made an architecture assumption that was actually a stakeholder assumption. Should the regulator have been in the original register? For grid telemetry, yes — residency regimes for critical infrastructure were foreseeable; the miss is an identification failure, not bad luck.

## Alternatives and evaluation criteria

- Lobbying for an exemption: a real option with a real clock; plan the architecture as if denied — never couple compliance posture to a hope.
