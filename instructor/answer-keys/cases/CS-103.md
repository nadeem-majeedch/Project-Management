# Answer key — CS-103 · Escaping the feature-store lock-in

> **INSTRUCTOR ONLY — not published to the site.**

**Model answer:** Abstraction-first escape

## Reasoning

Abstraction: define an in-house FeatureRequest interface (name, entity, time-range, freshness requirement) — the model reads the interface; a thin adapter routes to the vendor store today and to the in-house warehouse as features migrate. The boundary is real because the model code changes once and never again; the adapter is the only vendor-coupled artifact. Migration sequence: move features by (1) transformation simplicity — the 40 features that are plain aggregations move first (mechanical translation of DSL to SQL, verifiable row-by-row); (2) then the 15 complex features, each with the dual-run verification (CS-62's pattern: shadow-compute both paths for two weeks, compare distributions, then flip); (3) last, the 8 features whose DSL semantics are undocumented — these get reverse-engineered with the vendor's migration assistance priced into the exit (CS-79's clause pattern). Dual-run: every migrated feature is verified against the vendor's output for two weeks before the model switches — silent semantic differences (timezone handling, null semantics) are the migration's real risk, and comparison is the only defense. Negotiation posture: the 9-month clock inverts the leverage — at month 0, TelcoCare cannot leave; at month 9, the vendor's remaining hook is 8 features. The renewal strategy: sign a 12-month extension NOW at +10% (not 35%) with the migration running underneath; the posture is honest — 'we are leaving in a year unless the price reflects a customer with alternatives.' When is +35% right anyway: if the 9 months would consume more engineering than the +35% costs over five years — the escape must be priced against the alternative, not against zero.

## Alternatives and evaluation criteria

- Full migration before negotiating: cleaner position, and it spends 9 months of engineering on a hedge — the extension-plus-migration path buys the same leverage for a tenth of the cost.
## Facilitation

Ask what the interface costs to build even if the migration is cancelled — two weeks; the cheapest option in the case is also the one that creates all the others.
