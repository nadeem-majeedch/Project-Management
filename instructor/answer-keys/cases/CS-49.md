## Reasoning

Forward: A 0–3; B 3–7; C ES = 7+2 = 9, EF 11; D 7–12; E 11–14; F ES = 12+1 = 13, EF 17; end 17. Backward: F LS 13; E LS 14; C LF = E.LS = 14, LS 12 (TF = 12−9 = 3); D LF = F.LS−1 = 12, LS 7 (TF 0); B LF = min(C.LS−2 = 10, D.LS = 7) = 7, LS 3 (TF 0); A LS 0 (TF 0). Critical path A–B–D–F = 17 wk; near-critical C–E at TF 3. C's free float: E can start at 11, C finishes at 11 — FF = 0 while TF = 3. Translation: C may slip 3 weeks before the project slips, but any C slip immediately delays E's start; the buffer belongs to the chain, not to C alone.
