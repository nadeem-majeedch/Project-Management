# Answer key — CS-12 · Three-level WBS for the student portal

> **INSTRUCTOR ONLY — not published to the site.**

**Model answer:** Deliverable WBS + roll-up audit

## Reasoning

Roll up bottom-up: work packages → deliverables → project. The 100% rule means each parent equals the sum of its children — no 'miscellaneous' bucket, no unallocated hours. Duplicate estimates resolve by the newest estimate wins if a basis-of-estimate date exists; otherwise re-estimate once with the estimator who owns the work. Averaging hides disagreement instead of resolving it.

## Alternatives and evaluation criteria

- Averaging duplicates: defensible when both estimates have equal basis quality and the disagreement is symmetric; state it as a deliberate rule if used.
