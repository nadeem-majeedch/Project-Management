# Answer key — CS-40 · Benefits map and compute footprint

> **INSTRUCTOR ONLY — not published to the site.**

**Model answer:** Owned benefits + quantified footprint

## Reasoning

Benefits map: churn reduction (owner: marketing lead; measure: quarterly retention delta), analyst time saved (owner: analytics manager; measure: report hours), campaign precision (owner: campaign lead; measure: conversion uplift). Footprint: A = 288 GPU-h → 115.2 kWh → 69.12 kg CO₂e → PKR 4,032; B = 160 GPU-h → 64 kWh → 38.4 kg CO₂e → PKR 2,240. The electricity cost is trivial next to the PKR 4.2M benefit — the honest analysis says the 0.3-point accuracy gap is worth PKR 1,792 and 30.7 kg CO₂e, which is a strategy-A call on accuracy grounds; the sustainability case for B needs a scale argument (retraining cadence), not this single run.

## Alternatives and evaluation criteria

- Choosing B on footprint grounds: defensible under a retraining-cadence argument (52 runs/year multiplies the gap); must be stated as such, not from single-run numbers.
