# Answer key — CS-91 · The specialist two projects are fighting over

> **INSTRUCTOR ONLY — not published to the site.**

**Model answer:** Cross-project leveling with costed options

## Reasoning

Overload: weeks 3–6 demand 4 days against 3 capacity — four weeks, one day over each. Delay analysis: P2 must start late enough that its first week ends after P1's last — P2 start + 1 > 6 → start week 6... verifying: P2 occupies weeks (3+d)–(8+d); overlap with P1 (weeks 1–6) requires 3+d ≤ 6 for conflict → conflict clears when 3+d > 6, d = 4. But P2's float is 3 weeks: the move exceeds float by one week → 50k penalty. Options: (a) delay P2 by 4 weeks — 50k penalty, P2 ends a week late; (b) temp specialist for the 4 overloaded weeks — 120k, no penalty; (c) hybrid: delay P2 by 3 weeks (within float, no penalty) + temp for the 1 residual overlap week — 30k. The hybrid wins: 30k against 50k and 120k. Recommendation: hybrid, with the arithmetic shown to both PMs — the conflict was never about the specialist, it was about arithmetic nobody had run. Governance fix: shared specialists get a visible portfolio-level allocation calendar with commitment rules (changes need portfolio approval, not first-come-first-served), and float consumption by one project of another's slack requires the portfolio manager's sign-off — float is portfolio property.

## Alternatives and evaluation criteria

- Split the specialist 1.5/1.5 across the overload window: both projects run at partial speed, both slip informally, neither baseline survives — the unmanaged default this case exists to prevent.
