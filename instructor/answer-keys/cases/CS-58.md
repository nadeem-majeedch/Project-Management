# Answer key — CS-58 · Build-vs-subscribe TCO

> **INSTRUCTOR ONLY — not published to the site.**

**Model answer:** Cumulative TCO with crossover

## Reasoning

Build: y1 = 300+60+24+100 = 484; y2 = 84 → 568; y3 = 84 → 652; y4 = 84 → 736. Subscribe: y1 = 30+180 = 210; y2 = 189 → 399; y3 = 198.45 → 597.45; y4 = 208.37 → 805.82. Three-year: subscribe wins by 54.55k. Crossover: build adds 84k/yr, subscribe ~208k/yr → 54.55 ÷ (208.37−84) ≈ 0.44 → mid-year 4. Decision for a university portal with a decade horizon: build — but the arithmetic understates build's real cost: the 60k maintenance line assumes an engineer who knows the code stays; staff turnover makes maintenance lumpy, and the compliance review is an underestimate of audit burden. The honest recommendation: subscribe if integration depth is shallow, build if signing must weave into student-record workflows — the crossover math is necessary but not sufficient.

## Alternatives and evaluation criteria

- Hybrid: subscribe now, rebuild in-house at year 3 if volumes justify: pays the onboarding twice; defensible only if the 5% escalation is expected to worsen.
