# Answer key — CS-29 · Definition-of-Done workshop

> **INSTRUCTOR ONLY — not published to the site.**

**Model answer:** Minimal enforceable DoD

## Reasoning

Seven items: code reviewed; unit tests pass; integration test green in CI; documentation updated; feature flag or rollback path defined; demo-ready on the shared environment; no known critical defects. External testability: each item names who verifies (reviewer, CI, PO). The honesty rule: unfinished items return to backlog — the story does not count toward velocity. DoD vs AC: DoD is the same for every story (quality floor); AC is per-story (what it must do). Mid-project DoD changes are allowed via retrospective, never mid-sprint.

## Alternatives and evaluation criteria

- Adding security-review to DoD: right instinct; if no security capability exists, it becomes a checklist lie — add it as a separate gate until real.
## Facilitation

Run the 'is it done?' drill on three fake submissions; watch the team's own checklist catch or miss each.
