# Answer key — CS-05 · RACI for a campus portal team

> **INSTRUCTOR ONLY — not published to the site.**

**Model answer:** Single-accountability RACI

## Reasoning

Both incidents are accountability gaps: the deploy lacked a C gate (registrar review) and the register had no A (PM owns register upkeep). The fix assigns registrar C on deploy-gated activities and PM A on the register with a named update cadence. The contested A is UAT sign-off: registrar owns acceptance (A) because acceptance is a user-side judgment; developers stay R.

## Alternatives and evaluation criteria

- Sponsor as A for UAT: defensible when acceptance is political, but it removes the actual user voice from acceptance.
## Facilitation

Let students discover the 'too many Cs' pathology themselves by tallying their first-draft matrix.
