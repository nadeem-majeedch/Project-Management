# Answer key — CS-07 · Hybrid decision for a regulated data product

> **INSTRUCTOR ONLY — not published to the site.**

**Model answer:** Gated-continuous hybrid

## Reasoning

Gate the release, not the iteration: sprints continue producing validated increments, and the gate board reviews a standing package (test evidence, change log, residual-risk note) rather than ad-hoc submissions. Bottleneck mitigation: pre-submission readiness check by QA lead so the board only sees complete packages; second mitigation is a delegated fast-track for low-risk changes with retrospective board review.

## Alternatives and evaluation criteria

- Sprint-aligned gates (gate every sprint boundary): maximally predictable but couples the board's calendar to delivery and stalls flow at every boundary.
- Continuous release with post-hoc audit: fastest, acceptable only where the regulator permits retrospective evidence.
## Facilitation

Ask what happens to a hotfix; the hotfix path is where hybrid designs usually break.
