# Answer key — CS-67 · The platform bet: scenario NPV

> **INSTRUCTOR ONLY — not published to the site.**

**Model answer:** Scenario NPV with break-even

## Reasoning

Annuity factor = 3.1699. NPVs: good = 900×3.1699 − 2000 = +852.9k; base = 600×3.1699 − 2000 = −98.1k; bad = 200×3.1699 − 2000 = −1366.0k. Expected NPV = 0.3(852.9) + 0.5(−98.1) + 0.2(−1366.0) = −66.4k → reject as structured. Break-even: E = p×852.9 + (0.8−p)(−98.1) + 0.2(−1366.0) = 951.0p − 351.7 → p* = 0.3698. The sponsor needs to believe the good scenario is ~37% likely, not 30%. What the analysis ignores: option value — the platform creates capabilities (data products, faster experiments) whose value is not in the four-year inflow lines; that is why negative-EVPV platform bets sometimes proceed, but the option value must be argued, not assumed.

## Alternatives and evaluation criteria

- Restructuring to reduce the 2.0M outlay (phased platform): raises every scenario's NPV mechanically; the honest version re-estimates the bad scenario's inflows too — phased platforms often deliver the bad case anyway.
