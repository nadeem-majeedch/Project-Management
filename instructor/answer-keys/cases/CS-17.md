# Answer key — CS-17 · Bottom-up budget for a data project

> **INSTRUCTOR ONLY — not published to the site.**

**Model answer:** Layered cost build-up

## Reasoning

Labor = Σ(hours × rate). Indirects = 25% × labor. Subtotal = labor + indirects + direct. Contingency = 10% × subtotal (PM-controlled, known-unknowns). Management reserve = 5% × (subtotal + contingency) (sponsor-controlled, unknown-unknowns). Baseline = subtotal + contingency; the reserve sits above the baseline and is released only through the sponsor. Headroom = cap − total including reserve.
