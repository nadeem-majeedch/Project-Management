# Answer key — CS-63 · Buying information: the PoC decision

> **INSTRUCTOR ONLY — not published to the site.**

**Model answer:** Decision tree with EVPI

## Reasoning

Custom EMV = 0.6×1,200,000 − 400,000 = 320,000. Vendor net = 700,000 − 300,000 = 400,000 → vendor wins today. With perfect info: success branch → build (1,200,000 − 400,000 = 800,000); failure branch → vendor (400,000). EV = 0.6×800,000 + 0.4×400,000 = 640,000, minus the 80k PoC = 560,000 — beats 400,000 by 160k. EVPI (gross, before PoC cost) = 640,000 − 400,000 = 240,000; the PoC at 80k buys information worth 240k → buy. Reversal condition: if PoC price exceeds 240k or its information is materially imperfect, decline. The insight students miss: the vendor option wins today, yet the PoC is still worth buying — its entire value is the 40% branch where it saves you from the mediocre certain option.

## Alternatives and evaluation criteria

- Building an imperfect PoC for 80k that reveals success with 90% fidelity: EV recompute shows value shrinks but stays positive; the full-information number is the ceiling, not the offer.
