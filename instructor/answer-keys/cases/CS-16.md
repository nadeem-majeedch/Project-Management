# Answer key — CS-16 · Gantt baseline and resource levelling

> **INSTRUCTOR ONLY — not published to the site.**

**Model answer:** Float-bounded levelling

## Reasoning

Move the floated activity into its 4-day float window; the specialist's conflict resolves without touching the critical path. The cost: the floated activity now has zero float — any further slip makes it critical, so the project's resilience decreased even though the end date is unchanged. The cross-deliverable move is justified only if the receiving deliverable's float can absorb it; otherwise it just relocates the conflict.

## Alternatives and evaluation criteria

- Splitting the specialist's time 50/50: defensible if context-switching cost is low; usually it is not for deep technical work.
- Requesting a second specialist: costs money, preserves float — the right call when float is nearly exhausted elsewhere.
## Facilitation

Make students state the new float of the moved activity; 'it fit' is not an answer.
