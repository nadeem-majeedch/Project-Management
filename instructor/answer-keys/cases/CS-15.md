# Answer key — CS-15 · Hand-solved 14-activity CPM network

> **INSTRUCTOR ONLY — not published to the site.**

**Model answer:** Two-pass CPM

## Reasoning

Forward pass: EF = ES + duration, ES = max(EF of predecessors). Backward pass: LF = min(LS of successors), LS = LF − duration. Total float = LS − ES; free float = ES(successor) − EF. Critical path = zero total float. Free float can be less than total float when successors start earlier than their late dates; free float 0 with total float 2 means the successor is on the critical path. A near-critical path one week away means crashing decisions must check both paths — compressing only the critical path can promote the other.
