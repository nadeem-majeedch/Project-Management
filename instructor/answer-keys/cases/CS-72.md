# Answer key — CS-72 · WBS dictionary disputes

> **INSTRUCTOR ONLY — not published to the site.**

**Model answer:** Boundary-standard dictionary

## Reasoning

Entry rewrite pattern: 'Develop reporting module' becomes deliverable description (six named reports, defined filters, CSV export of listed fields), in/out boundaries (in: server-rendered reports; out: ad-hoc query, scheduling, the export API — owned by WBS 3.2), acceptance criteria (each report renders from seeded data with expected row counts; export matches schema contract), effort, dependencies. Ownership rule: every WBS node has exactly one accountable owner; any work item whose home is ambiguous routes to the WBS owner for assignment within one day — ambiguity is resolved by rule, not by whoever builds first. The degradation happens mid-project under pressure: titles are faster to write, and the debt surfaces exactly at integration. Audit: PMO or PM verifies the 100% rule at each baseline change, not on a calendar.
