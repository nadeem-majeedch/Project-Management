# Answer key — CS-41 · Course retrospective as a closure drill

> **INSTRUCTOR ONLY — not published to the site.**

**Model answer:** Change-shaped lessons

## Reasoning

A lesson like 'case discussions ran long' is a complaint; 'cap case discussion at 25 minutes with a visible timer, apply in any discussion-led session, owner: session facilitator' is a lesson — it names the change, the context, and the carrier. Process lessons here: the estimate-calibration loop (CS-14's correction factor) is a reusable estimating habit; the working agreement (CS-34) is a reusable team-forming artifact. The question quadrant works when questions have answerable owners — 'would a 10-week version of this course drop Unit 5 or Unit 7?' is answerable by the instructor; 'why is scope always hard?' is not.

## Alternatives and evaluation criteria

- None recorded.
## Facilitation

Model the behavior: accept two lessons into next semester's plan publicly, visibly, immediately.
