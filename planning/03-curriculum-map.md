## Two-hour session template

Every lecture follows the same 120-minute shape (detailed timing in the
instructor lesson plan, not published):

| Slot | Segment |
|---|---|
| 0:00–0:10 | Hook — failure story, metric, or question from the tagline |
| 0:10–0:50 | Block 1 — first topic cluster with worked example |
| 0:50–1:00 | Break |
| 1:00–1:40 | Block 2 — second topic cluster + anchor case part 1 |
| 1:40–2:00 | Block 3 — third cluster, activity debrief, assignment pointer |

Bloom progression across the semester: Understand (W1–4) → Apply (W5–7) →
Analyze (W8–10) → Evaluate (W9–15) → Create (W14–16). Weeks overlap by design
because control (L19–L20) and negotiation (L26) require Evaluate while the
capstone integration (L27) requires Create.
